❓ FAQ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: Do I need the backend to use the app?
A: No! Manual search works without it. Backend just adds image scanning.

Q: Can I run without Docker?
A: Yes! Use Python setup scripts instead. Both work.

Q: What if backend crashes?
A: App will show helpful error. Use manual search. Restart backend.

Q: Does it need internet?
A: Only for first run to download OCR models (~500MB).

Q: How long does first image take?
A: 5-10 seconds (loading models). Then 1-2 seconds per image.

Q: Can I change the port?
A: Yes. Update: --port 8001 in start script and drugInfoService.ts
