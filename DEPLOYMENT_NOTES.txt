================================================================================
PERFORMANCE NOTES
================================================================================

Backend Latency:
  - First request: 5-10 seconds (model loading)
  - Subsequent requests: 1-2 seconds
  - Memory: ~2GB for PyTorch models
  - CPU-only acceptable, GPU much faster

Optimization:
  - Models are cached after first load
  - Preprocessing is fast (grayscale + denoise)
  - OCR is the bottleneck (1-2 seconds per image)

Backend won't start:
  → python3 scripts/setup-cv-backend.py

  → Change port: python -m uvicorn app:app --port 8001
  → Update frontend URL in drugInfoService.ts

Image processing fails:
  → Backend not running - see setup above
  → Use manual search as fallback
  → Check clear image quality
